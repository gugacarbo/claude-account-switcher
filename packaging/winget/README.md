# Upstream winget manifests

The manifests in this directory are retained from
[SnlperStripes/claude-account-switcher](https://github.com/SnlperStripes/claude-account-switcher).
They describe the upstream package `SnlperStripes.ClaudeAccountSwitcher`, not the
`gugacarbo` fork. Their publisher identity, download URLs and checksums must remain
associated with upstream releases.

This fork does not currently publish a separate winget package. Download its
binaries from https://github.com/gugacarbo/claude-account-switcher/releases.
Do not submit these manifests as releases of the fork or replace only their URLs.
A future winget package for this fork needs its own package identifier and metadata,
along with URLs and checksums for the fork's release assets.
